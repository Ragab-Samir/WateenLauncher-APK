# لانشر وتين (Wateen Launcher)

## البناء على GitHub (بدون Android Studio)
1. أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات هذا المجلد (بما فيها مجلد `.github`).
2. افتح تبويب **Actions** ← **Build Wateen Launcher APK** ← **Run workflow** (أو يبدأ تلقائياً عند الرفع).
3. بعد انتهاء البناء (حوالي 5 دقائق) افتح التشغيلة وحمّل **WateenLauncher-APK** من قسم Artifacts. بداخله `app-debug.apk`.

## التثبيت على الشاشة أو الهاتف
> **مهم جداً لتجنب خطأ فشل التثبيت:**
> - عند تحميل الملف من GitHub Artifacts ستنزل حزمة مضغوطة باسم `WateenLauncher-APK.zip`، **يجب فك الضغط عنها أولاً** على الكمبيوتر أو الهاتف لاستخراج ملف `WateenLauncher.apk` أو `app-debug.apk` وتثبيته. (تثبيت ملف الـ zip مباشرة يسبب فشل التثبيت).
> - إذا كانت هناك نسخة قديمة مثبتة على جهازك، يجب **إلغاء تثبيتها أولاً** قبل تثبيت النسخة الجديدة لتفادي تعارض التوقيع.
> - تأكد من تفعيل "تثبيت التطبيقات من مصادر غير معروفة" (Unknown Sources) للتطبيق الذي تستخدمه في التثبيت (مثل مدير الملفات أو متصفح).

1. إعدادات الجهاز ← الأمان والتطبيقات ← السماح بالتثبيت من مصادر غير معروفة.
2. انقل الـ APK عبر فلاشة USB أو تطبيق Send Files to TV أو `adb install WateenLauncher.apk`.
3. افتح اللانشر، ثم اضغط زر "تجاوز اللانشر الافتراضي" أو اضغط زر القائمة الرئيسية (Home) واختر وتين ← دائماً.

## التحكم بالريموت
- الأسهم: التنقل. OK: فتح. **OK مطولاً**: قائمة (تثبيت، نقل للألعاب، قفل، إلغاء تثبيت).
- Back لا يغلق اللانشر.

## الإعدادات (ملف Config.kt)
- `TOP_TEXT`: النص أعلى الشاشة.
- `GOLD_URL`: رابط JSON لأسعار الذهب (وإلا تبقى القيم الافتراضية).
- `NEWS_RSS_URL`: رابط RSS للأخبار.
- `HIJRI_OFFSET_DAYS`: تعديل التاريخ الهجري بيوم.
